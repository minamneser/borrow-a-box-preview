# Borrow A Box — Public Preview

Static website preview published through GitHub Pages. Original logo and four AI-generated service illustrations are retained.

## Booking preview

Four steps cover ZIP enquiries, packages, separate delivery/pickup dates and addresses, two-hour window preferences, extensions, optional extras and an itemized request. Seven calendar days are included. Up to 28 extra days cost $25/day, capped at $100 per seven-day block. Additional dollies cost $25 each. The New Jersey 48-hour cutoff is enforced.

Fragile kit and supply prices, delivery fees, tax and live availability remain unconfigured. Their prices are never assumed to be zero, and the final payable total remains pending. No inventory is reserved, payment processed, booking created or automatic email sent by this static preview. Request and contact forms prepare email drafts for visitors to send themselves; copy and download are also available for booking requests. Customer details are not persisted to browser storage.

Reviews, About Us, Contact, preview rental terms, expanded FAQs and a future Partners page are included. No unverified aggregate star rating or review count is claimed.

## Maintenance

Active package prices and policy constants are in catalog.js. Pricing and New Jersey date logic are in rental-model.js. checkout.js manages booking state, and site.js manages navigation, price display and contact drafts. Integrate a secure backend before enabling live inventory, payments and confirmation emails.

This repository contains the public preview; the working project is maintained separately. Third-party license notices remain with the assets.
